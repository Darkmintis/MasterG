# Game checklist

Use for `technical`, `retention`, `polish`, `revenue`. Cite file:line or screenshot.

## Core loop
- [ ] Clear loop: action → reward → reason to repeat
- [ ] First session teaches the loop without a wall of text
- [ ] Session length fits the genre (idle vs match-3 vs deep)

## Difficulty & rewards
- [ ] Difficulty curve: not brick-wall early, not endless trivial
- [ ] Reward pacing: not empty grind, not paywall-gated fun
- [ ] Soft currency / IAP: clarity; no dark patterns without calling them out

## Ads (if any)
- [ ] Between sessions / natural breaks — not mid-critical input
- [ ] Rewarded ads optional and labeled
- [ ] Frequency caps; not every death/level

## Technical / polish
- [ ] Performance on low-end targets claimed
- [ ] Pause / resume / audio interrupt handled
- [ ] Save progress / cloud save if sessions matter
- [ ] Crash reporting for live games

## Trust
- [ ] Age rating / content disclosures match content
- [ ] Privacy policy if analytics/ads present
